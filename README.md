# Intelligent Customer Intelligence & Predictive Analytics System

## Project Overview
A Machine Learning project that predicts whether a telecommunications customer is likely to leave a service (Customer Churn Prediction).

## Dataset
IBM Telco Customer Churn Dataset.

## Machine Learning Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Gradient Boosting
- XGBoost

## Model Optimization
Hyperparameter tuning was performed using RandomizedSearchCV for Random Forest and XGBoost.

## Final Model
Tuned Random Forest Classifier.

| Metric | Score |
|---|---:|
| Accuracy | 75.87% |
| Precision | 53.14% |
| Recall | 77.01% |
| F1 Score | 62.88% |
| ROC-AUC | 84.28% |

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Plotly

## Run Locally

Install dependencies:
pip install -r requirements.txt


Run the application:
streamlit run app.py


## Application Features
- Customer analytics dashboard
- Customer churn distribution
- Contract-based churn analysis
- Interactive customer information form
- Customer churn prediction
- Estimated churn probability
